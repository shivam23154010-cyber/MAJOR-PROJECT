
# 🌐 Verbrix - Intermediary Platform for Global Healthcare Communication

Verbrix is a **full-stack web application** designed to bridge communication gaps in global healthcare by connecting international patients with verified interpreters.

The system provides a **secure, structured, and real-time platform** for communication, consultation, and payments.

---

## 🧭 Overview

Global healthcare travel often suffers from:
- Language barriers  
- Unverified intermediaries  
- Lack of transparency  
- Risk of fraud and miscommunication  

Verbrix solves this by offering:
- Verified interpreter marketplace  
- Secure communication channels  
- Transparent payment system  
- Structured interaction workflows  

---

## 🏗️ System Architecture

Verbrix follows a **3-layer architecture**:

### Frontend
- Angular 21  
- Tailwind CSS v4  
- Handles UI, user interaction, and real-time updates  

### Backend
- Spring Boot (Java 21)  
- REST APIs + WebSocket  
- Business logic, authentication, and integrations  

### Data Layer
- PostgreSQL → relational data  
- MongoDB → chat & logs  

---

## 🚀 Core Features

### 🔐 Authentication & Security
- OTP-based email verification  
- JWT authentication (access + refresh tokens)  
- Google social login  
- Device/session management  
- Role-based access control  

### 👥 Role System
- Client (Patient)  
- Interpreter  
- Admin  

### 🧾 Interpreter Verification
- Application with document upload  
- Admin approval system  
- Role transition (Client → Interpreter)  

### 🔄 Relationship Lifecycle

```text

REQUESTED → ACCEPTED → ACTIVE → TERMINATED

```

- Governs interaction between users  
- Enables/disables chat, video, and payments  

---

### 💬 Real-Time Communication
- WebSocket-based chat (STOMP)  
- Persistent message storage  
- Controlled access  

---

### 📹 Video Consultation
- LiveKit integration  
- Token-based secure access  
- Enabled only in ACTIVE state  

---

### 💳 Payment System
- Razorpay integration  
- Idempotent order creation  
- Payment verification  
- Automatic refund mechanism  

---

### 🛠️ Admin Module
- Interpreter verification  
- Application review  
- Platform monitoring  

---

## 🔗 External Integrations

- Razorpay — payment gateway  
- LiveKit — video communication  
- Cloudinary — file storage

## ⚙️ Setup Instructions

### 1. Clone Repository

```bash
git clone <repository-url>
cd verbrix
```

---

### 2. Backend Setup

```bash
cd backend
```

Configure:

`src/main/resources/application.yml`

Run:

```bash
mvn spring-boot:run
```

Backend runs on:

`http://localhost:8080`

---

### 3. Frontend Setup

```bash
cd frontend
npm install
ng serve
```

Frontend runs on:

`http://localhost:4200`
